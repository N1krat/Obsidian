High: 
1. cautarea produselor - (positiv ) o dat lista cu produse ce contin denumirea identica sau asemenatoare - (negativ ) o dat produse ce nu se incadreaza in cautare
2. Adaugarea produselor in cart - (positiv ) produsul dorit (nu altul aleatoriu) ales so adaugat in cart in numarul corect - (negativ ) so adaugat un produs aleatoriu sau numarul produselor nu este corespunzator 
3. checkout - (positiv) datele ce au fost introduse de catre user au fost salvate corespunzator si nu au aparut nici un fel de erori - (negativ) au aparut probleme cu procesarea checkoutului 
4. procesarea platii - (positiv ) plata o trecut cu succes si de pe card sau dus suma corecta - (negativ) plata nu a trecut cu succes la noi sau la banca. Sau suma extrasa nu corespunde adevarului 
5. autentificarea / inregistrarea unui cont - (positiv) user-ul a reusit sa creeze un cont cu succes si deja poate sai faca management. - ( negativ ) inregistrarea nu a fost cu succes din cauza unei erori sau datele introduse de catre user nu au fost prelucrate corespunzator 

Medium: 
1. Istoricul comenzilor - (pozitv) userul are posibiliatea de a accessa din cabinet istoricul comenzilor pentru a monitoriza toatele comenzile ce au fost facute anterior - (negativ) istoricul comenzilor nu lucreaza / istoricul comenzilor poate fi incarcat gresit de ex un user sa aiba istoricul altui user
2. aplicarea codurilor de reducere / vouchere - (pozitiv) userul introduce codul pentru reducere care este verificat cu succes si este aplicat deja asupra sumei produselor din cart - (negativ) nu se poate verifica valabilitatea codurilor de reducere sau a voucherilor 
3. recuperarea parolei - (pozitiv) utilizatorul primeste pe posta sau sms pentru recuperare a parolei ce este unic pentru el - (negativ ) userul nu primeste nici un fel de email/sms pentru a incepe procesul de recuperare a parolei

Low: 
1. Modificarea datelor de profil - (pozitv) userul poate face rename la username, email, poza de profil si alte date personale - (negativ ) nici una din schimbari nu poate fi salvata cu succes 
2. abonarea la newsletter - ( pozitv ) userul va accepta optiunea pentru newsletter si va primi o data in intervalul specificat un mesaj promotional - (negativ ) mesajele nu vor fi receptionate de catre client din cauza unei erori 
3. lasarea unei recenzii sau acordarea unei note unui produs - (pozitiv) alti utilizatori vor putea vizualiza recenzia sau o sa observe modificarea la nota produsului - (negativ ) recenzia nu se va salva sau alti utilizatori nu vor putea vedea nota lasata de alt utilizator 
4. scimbarea limbii - ( pozitiv ) pe platforma limba va fi setata in cea dorita de utilizator - (negativ) nu o sa fie nici un fel de schimbari sau ele vor fi gresite 
5. marirea imaginii produsului - (pozitiv ) utilizatorul poate manipula cu imaginea produsului marindo sau micsorando - ( negativ ) functie de zoom va distorsa imaginea intrun mod negativ sau ea nu va fi afisata corect pe dispozitiv.
