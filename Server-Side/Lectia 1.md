_**Internetul**_ - este o infrastuctura globala care conecteaza diverse dispozitive permitand interactiunea intre acestea. ( HTTP/HTTPS, POP, EMAIL, FTP, SSH, VOIP, etc )

_**World Wide Web**_ - unul din serviciile pe internet. El foloseste _hyperlinks_ pentru a accesa diverse sisteme de pagini si resurse interconectate. Resursele web pot fi: text, imagini, audio, video, forms etc.

_**Server**_ - este un computer ce ofera servicii altor computere sau dispozitive de retea. Serveru poate avea diverse sarcini in functiune de rol si scop. ex: 
- Server Web: apache, nginx 
- Server pentru BD (mysql, postgresql)


| Client side                      | Server side                  |
| -------------------------------- | ---------------------------- |
| Se executa in browser            | Se executa pe server         |
| HTML, CSS, JS                    | PHP, Python, Java, C#        |
| Construieste interfata           | Proceseaza datele            |
| Codul ajunge in browser          | Codul sursa ramane pe server |
| Nu acceseaza direct baza de date | Poate accesa baza de date    |

_**Host**_ - orice dispozitiv conectat la retea 

Structura unei adrese URL: 

https://universitate.md/studenti/profil?id=25 

https:// - protocol 
universitate.md - domain 
studenti/profil - cale 
id=25 - parametru
