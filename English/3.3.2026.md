## Topic: Stacked Area Chart

![[Pasted image 20260302184736.png]]


We call it _area chart_ because the data from each category is shown as a field area ( a colored region, not just a line ). The size of the shaded area represents the value over time. 

_Stacked_ - because the categories are placed on top of each other, each new category is added above the previous one. 

( stacked == added )

The top line shows the total population, the individual colored sections show how much each group contributes to that total. 

On a stacked area chart you can see both, _overall growth_ and _composition changes_ at the same time.
