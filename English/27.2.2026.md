# Lesson 19 Writing

## Topic: Introduction to IELTS Writing 


IELTS Writing module is the third to be tested. 

Time: 60 min ( 20 task 1 + 40 task 2 )

There are 2 sections: 
1. Graph description ( min 150 - 180 words optimal )
2. Essay writing ( min 250 - 280 words ). They check 4 types of essays: 
	1. Opinion essay 
	2. Discussion essay 
	3. Problem solution essay 
	4. Advantages and disadvantages essay

We are writing academical essays. 

Never submit your work unless you have checked: 
1. Formal register ( no contractions ex: don't etc )
2. Clear introduction (Both tasks must have a clear introduction, a poor introduction means a poor essay  )
3. Logical paraphrasing ( no repetition accepted )
4. Linking devices used correctly 
5. Critical evaluation must be included (read the essay before submitting and evaluate it )
6. Evaluate punctuation 
7. Check you have all the paragraphs 
8. In task 1 you must have an overview paragraph 
9. Vary vocabulary ( avoid lots of repetitions )
10. Accurate grammar
